# Code of conduct

This is a small project. The rule is short: be decent to people.

Concretely, that means assuming the other person is trying to help, keeping
criticism about the code rather than the person, and accepting that a
maintainer's time is a gift rather than a service you are owed. Harassment,
insults, and abuse of any kind are not welcome here, in issues, pull requests,
or anywhere else this project happens.

If someone is making this project a worse place to be, write to
[the maintainer](https://github.com/charles-martech). Reports are handled
privately. Depending on what happened, the response ranges from a quiet word
to a block from the repository.

This applies to everyone taking part, maintainer included.
